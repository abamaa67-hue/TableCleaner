# TableCleaner

**TableCleaner** — настольная программа для Windows на Python, предназначенная для очистки таблиц CSV и Excel. Она помогает быстро находить и удалять лишние данные, приводить таблицы в порядок и сохранять очищенные результаты.

## Возможности

- 📂 **Открытие таблиц** — поддержка файлов CSV и Excel (`.xlsx`).
- 👀 **Предпросмотр данных** — просмотр содержимого таблицы перед обработкой.
- 🧹 **Удаление пустых строк** — очистка строк, не содержащих данных.
- 🔁 **Удаление дубликатов** — удаление полностью повторяющихся строк.
- ✨ **Очистка пробелов** — удаление лишних пробелов в начале и конце текстовых ячеек.
- ↩️ **Отмена изменений** — восстановление предыдущего состояния таблицы после очистки.
- 💾 **Сохранение результата** — экспорт очищенной таблицы в отдельный файл.
- 🎨 **Темы оформления** — светлая, тёмная и автоматическая тема в зависимости от оформления Windows.
- ⚙️ **Настройки приложения** — настройка предпросмотра и поведения операций очистки.

## Установка и запуск

### Запуск из исходного кода

1. Установите Python.
2. Скачайте или клонируйте репозиторий.
3. Откройте папку проекта в VS Code.
4. Установите зависимость:

   ```powershell
   python -m pip install openpyxl
   ```

5. Запустите приложение:

   ```powershell
   python main.py
   ```

Если используется виртуальное окружение `.venv`, сначала активируйте его или запускайте программу через `.venv\Scripts\python.exe`.

### Запуск готовой версии

Готовую сборку для Windows можно скачать из раздела **Releases**, если она опубликована.

## Структура проекта

- `main.py` — точка входа в приложение.
- `app.py` — инициализация и управление приложением.
- `main_window.py` — главное окно и предпросмотр таблиц.
- `settings_ui.py` — настройки и оформление.
- `data_operations.py` — загрузка, очистка, отмена и сохранение данных.
